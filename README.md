🛒 E-Commerce Sales Data Analysis

📌 Project Overview

This project analyzes an E-Commerce Sales dataset to uncover insights into sales performance, product categories, customer behavior, and regional trends.
The analysis aims to support data-driven decision-making by identifying top-selling products, high-revenue categories, and sales patterns over time.

The entire project was completed using Google Colab with Python.

🛠 Tools Used

Google Colab – Cloud-based analysis environment

Python – Programming language

Pandas – Data cleaning and transformation

NumPy – Numerical analysis

Matplotlib & Seaborn – Data visualization

🎯 Dataset

Source: Public / Sample E-Commerce Sales Dataset

Key Columns:

Order_Number – Unique order ID

Customer_Name – Customer name

Order_Date – Date of order

Product – Product name

Category – Product category

Brand – Product brand

Quantity – Units sold

Sales – Sales amount

Cost – Product cost

Total_Sales – Revenue generated

State_Code – Customer region

🔄 Workflow

Data Import & Inspection

Loaded dataset into Google Colab

Reviewed structure, data types, and missing values

Data Cleaning & Preprocessing

Handled missing and duplicate values

Converted date and numeric columns

Standardized categorical data

Feature Engineering

Calculated total sales and cost metrics

Extracted time-based features (month, year)

Exploratory Data Analysis (EDA)

Category-wise and product-wise analysis

Regional sales comparison

Trend and pattern analysis

Visualization

Sales by category

Top-selling products

Sales trends over time

Regional sales distribution

🔑 Key Insights

A small number of product categories contribute to the majority of revenue

Certain products consistently generate high sales across regions

Sales show clear monthly and seasonal trends

Regional demand varies significantly by product category

High-value products generate more revenue with lower quantities sold
